[功能 - 新聞]
- 三語（繁中/英/西）；中文一律繁體（DeepL target ZH-HANT，UI 標籤亦繁體）
- 首頁：三語切換、搜尋、主題（邊境/航空）/ 時間過濾、卡片（含圖，無圖自動放 El Paso/Juárez 風景照＋「非新聞照片」標籤）
- 點卡片 → 閱讀視窗：
  - 80vh 彈窗（桌面左圖右文 50/50，手機全螢幕）
  - 多圖輪播（左右滑）、點圖 → 全螢幕燈箱（可縮放、平移）
  - 翻譯全文 + 原文直接顯示在下方，**不切換 toggle**
  - 自動翻譯透過 GET /api/translate?id=<uuid>&lang=zh|en|es，server route 帶 DEEPL_API_KEY + SUPABASE_SERVICE_ROLE_KEY，結果快取到 content_zh / content_es（第二次點開秒開、不重扣 DeepL）
- 相關性過濾：`app\crawler\filters.py` 的 EXCLUDE_KEYWORDS（運動/娛樂/名人/星座/彩券）、LOCAL_SOURCES（純在地白名單）、LOCAL_SIGNALS（在地關鍵字）、AVIATION_RELEVANCE_KEYWORDS（僅航班問題/政策）

[功能 - 航班追蹤]
- 兩欄 UI：左 = 待出發、右 = 已出發（依起飛時間/抵達時間由近到遠排）
- 卡片極簡：班號 + 航空公司名 + 機型 + 起飛/抵達時間 + 燈號 + 更新按鈕
- 燈號：
  - 左燈（起飛狀態）：空心 = 未出發；藍 = 提早 ≥15 分鐘出發；綠 = ±15 分鐘準點；黃 = Delay 15~30 分鐘；紅 = Delay ≥30 分鐘；黑（閃爍）= 取消
  - 右燈（抵達狀態）：藍 = 提早 ≥15 分鐘抵達；綠 = ±15 分鐘準點；黃 = Delay 15~30；紅 = Delay ≥30；黑（閃爍）= 不會抵達（轉降/取消）
- 匯入 CSV：可從 WebUI 直接貼文字（5 欄：日期/起飛機場/抵達機場/航班代號/航班數字；2 欄 optional：airline_name/aircraft_type；日期格式吃 ISO 與美式 M/D/YYYY）
- WebUI 提供 Excel 範本下載 + 檔案上傳
- 更新燈號：WebUI 點「更新」按鈕 → 選擇 status / 填時間 / 標記已備份 → PATCH 寫回 DB
- 自動備份：航班抵達後 1 小時 daemon 自動標記 archived_at（下次抓取時不再顯示）

[功能 - OpenSky 自動確認]
- Python daemon 跑在員工 24x7 電腦（`app\flight_tracker\flight_tracker.py`）
- 每 15 分鐘：撈「未出發/未到」的航班 → OpenSky Network bbox 查詢（起飛/抵達機場周圍）→ 匹配 callsign（例如 WN756 ↔ SWA756）
- 匹配中 → 標記 departed/arrived；3 小時內不重查
- 無法確認的航班**由人工 WebUI 補**（這是 prototype 的限制）

[技術選擇理由（公司可參考）]
- DeepL Free API：中文品質最佳，但 ToS 限 non-commercial；公司用應升級 Pro（≈ $0.18/月）
- OpenSky Network：免費、即時、全球、無 API key；唯一缺點是無延誤分鐘
- 全文翻譯：嘗試過 Gemini + Google Search grounding（要 billing）→ DuckDuckGo HTML scraping（被擋）→ AeroAPI $89/月 → 最終採按需 + DB 快取的免費方案
- 持久 Git 憑證：%USERPROFILE%\.git-credentials + credential.helper=store；PortableGit 內建的 manager helper 已停用

[部署 - 24x7 電腦]

   - Task 名稱：`PMX Flight Tracker`
   - Trigger：每 15 分鐘重複（forever）

   - Start in：專案根目錄

[API contract]
- GET /api/flights?archived=false → { flights: [...] }（anon key 可讀）
- POST /api/flights/import body { text: "csv..." } → { upserted, skipped, flights }（service_role）
- PATCH /api/flights/[id] body { status?, actual_dep?, actual_arr?, scheduled_dep?, scheduled_arr?, notes?, updated_by?, airline_name?, aircraft_type?, archived? } → { flight }（自動算 delay_minutes 與 departure_delay_minutes；service_role）
- GET /api/translate?id=<uuid>&lang=zh|en|es → { content, translated, cached, note }（service_role）
